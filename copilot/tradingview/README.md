# TradingView-indikator

`ai_copilot_nivaaer.pine` tegner støtte/motstand, trendlinjer og volum-POC rett i TradingView-chartet. Reglene er de samme som i backend-analysen.

Slik legger du den til:
1. Åpne **Pine Editor** (fanen nederst i TradingView).
2. Slett innholdet, lim inn hele filen og trykk **Lagre**.
3. Trykk **Legg til i diagram**. Innstillingene endres via tannhjulet på indikatoren.

TradingView lar ikke eksterne programmer tegne i chartet. Derfor kan ikke AI-anbefalingene (kjøp/salg-soner fra Claude) vises her. De vises i panelet og på live-chart-siden («Åpne chart med nivåer …» i Analyse-fanen).
